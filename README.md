An application for ordering sandwiches with customizable options to match your personal taste.

## Description
3.	Best Sandwich is a Point of Sale (POS) application that enables customers to customize their sandwich orders, including options for drinks and chips.
4.	The system provides an interactive, console-based experience that guides users through each step, from building a sandwich to selecting add-ons and completing checkout.
## Features
Custom sandwich builder (bread type, size, meats, cheese, toppings, toasted option)
Optional drink and chip selection
Order summary with calculated pricing
Order persistence via transactions.csv
